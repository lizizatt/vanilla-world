# browser/ tech-debt sweep (phase 1: report only, nothing deleted)

Method: static scan of every `browser\*.js|mjs` export (referenced by any other file, split prod vs test), long functions, TODO/shortcut comments, empty catches, constant duplication, mirror/legacy grep. Counts are from the sweep at commit time; "prod" means non-test files. Rust (`pkg`, wasm) was not inspected.

## Top 10 (ranked by risk x cost)

1. **(Resolved: `shell-manifest.mjs` generates the list; tests cover it.)** Hand-maintained file lists drift (3 places). A new browser file must be added to the `server.mjs` allow regex, the `sw.js` precache list, and `build-dist.mjs` (`appFiles`/`vehicleFiles`). Missing one fails only at runtime or on the hosted build. Fix: derive all three from one manifest (or a test that diffs `import` graph vs each list).
2. **JS mirrors of shader/Rust logic can drift.** `cloud-march.js` mirrors the `clouds.js` WGSL extent/density (kept honest only by `clouds-sweep`/`clouds-shell` tests; the DOWN-billow cut bug hid in exactly this gap). The whirlpool dip lives in `clouds.js` `WHIRLPOOL_DIP` (+ `ocean-mesh.js`, `world-worker.js` `set_whirlpool` -> Rust) while `water-shader.js` has a separate `WHIRLPOOL` (radius 2600 vs 2400) and `MAELSTROM` has its own radii. One shared "maelstrom" config module + a consistency test would remove three sources of truth.
3. **Giant functions / files.** `world-worker.js` `handle` (153 lines) and `updateScene` (121), `track-editor.js` `createTrackEditor` (203), `world-renderer.js` (1101 lines, ~112 methods), `world-app.js` (813 lines, 18 empty `catch{}`), `scene-stream.js` (913). Split by concern; the renderer is also lead 2's active area, so do last.
4. **Empty `catch{}` swallowing errors.** `world-app.js` x18, `world-audio.js` x4, `vehicles.js` x1; mostly localStorage but some hide real failures. Replace with a tiny `safe(fn)` helper that logs once in debug.

## Other observations
- `PLANET_RADIUS` (space.js) and `HYJAL_SUMMIT`/cloud altitude (clouds.js) are single-sourced; good. `CLOUD_ALTITUDE_FACTOR`, `FUNNEL` are only consumed by tests/in-file.
- `clouds.js` shaders are string-built twice (`build(false)`/`build(true)`); a shader regex test suite guards them but there is no WGSL compile in CI-less `node --test` (only caught visually).
- No tracked `test-results`; `node_modules`/`pkg` are local junctions (fine).
