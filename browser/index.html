What this browser MVP includes
An alternate web rendering adapter using actual Rust physics and client formats, not a Bevy/VMaNGOS port or singleplayer RPG. Complete coarse continents, untextured detailed terrain, authored nearby models/textures and optional static bind-pose NPCs. Four detailed tiles stream around you; missing terrain holds the vehicle rather than becoming ocean. Scene collision uses conservative authored hull bounds, not exact interiors. Distant props, animated NPCs, quests and combat are not implemented. The 8192-yard ocean and Eastern Kingdoms' southward placement are provisional geography.
