About this local world
An alternate web rendering adapter using actual Rust physics and client formats, not a Bevy/VMaNGOS port or singleplayer RPG. Complete coarse continents, layered detailed terrain, authored models/textures and optional static NPCs. Four collision tiles and up to twelve separate visual metadata tiles stream around you; missing terrain holds the vehicle rather than becoming ocean. Distant models reach up to 6000 yards within shared cache limits, with real alpha and depth. Collision uses authored triangles, independently of visual texture arrival. Native-style controls, instruments, tuning and procedural engine sound remain fully local. Exact rider cockpit, full animation, quests and combat are not implemented. The 8192-yard ocean and Eastern Kingdoms' southward placement are provisional geography.
