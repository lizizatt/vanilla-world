Original chunky low-poly fantasy racer, built entirely from procedural geometry and flat-color materials without external art, textures, or game files. Each embedded GLB contains **4,819 triangles**: `dug-racer.glb` (`dug_default`, ochre/brass), `dug-racer-green.glb` (`dug_goblin_green`), and `dug-racer-crimson.glb` (`dug_crimson`). All variants use meters, +Y up, forward -Z, and a ground-level origin centered between the engines; dimensions are approximately 5 m wide, 5.8 m long, and 3 m tall. Named group nodes are `Body`, `EngineL`, `EngineR`, and `Cockpit`; `ExhaustL` and `ExhaustR` are empty attachment nodes at the rear nozzle mouths (exhaust travels toward +Z). Regenerate with Blender 2.90 or later using `blender -b -P tools\vehicles\make_dug_racer.py`; the script re-imports every export and asserts the node names, attachment types, triangle budget, scale, and ground height. Optionally append `-- --preview <path.png>` to render a single studio preview outside the repository.
